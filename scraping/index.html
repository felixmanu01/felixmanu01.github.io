Debaser concert scraping.

A Node.js project that collects public concert listings from Debaser, reads them with Cheerio and saves the result as a text file. The same data feeds the Gig Radar case, where it's combined with two music APIs.

Type
Web scraping
Stack
Node.js, Cheerio
Output
scraped_data.txt

How it works

Debaser

The public concert page is the source.

Node.js

A script fetches the page.

Cheerio

Reads artist, date, venue and genre from the HTML.

Text file

Every event is saved to a text file.

  • script.txtThe Node.js code that collects the data
